# ICT Day Papers — Cropped Quiz App

Fresh quiz app for PHY 01–21 using the newly cropped original question images and matching marking/explanation images.

- 21 day papers
- 126 questions
- 5 choices each
- Original Sinhala-containing question crops
- Matching original marking crops shown after answering
- Save/bookmark, progress, previous/next, results
- Static deployment ready for Netlify

Source crop archive is backed up in Google Drive under **ICT Day Papers Fresh Quiz App**.
